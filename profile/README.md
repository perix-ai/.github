### An agent network built to get work done

Perix is building an end-to-end AI agent network that takes a goal from request to follow-through. It routes work to the right agents, connects the context and tools they need, and coordinates execution across multi-step tasks.

### What we’re building

- **Agent networks** — compose specialized agents and coordinate work across them.
- **End-to-end execution** — take tasks from understanding and planning through action and delivery.
- **Persistent context** — carry relevant memory, knowledge, and project context across work.
- **Governed actions** — make execution observable, permission-aware, and auditable.
- **Open, connected systems** — bring agents and tools together across services and environments.
